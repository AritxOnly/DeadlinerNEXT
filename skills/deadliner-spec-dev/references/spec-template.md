# Spec Template

## `spec.md`

```md
# <Feature Title>

## 背景

## 目标

## 非目标

## 用户场景

## 验收标准

## 风险与约束
```

## `module-plan.md`

```md
# <Feature Title> Module Plan

## 模块拆分

## 平台映射

## 文件拆分策略

## 风险点
```

## `tasks.md`

```md
# <Feature Title> Tasks

## 阶段 1：规格冻结

## 阶段 2：基础设施

## 阶段 3：功能实现

## 阶段 4：验证与回写
```

## 建议

- 标题尽量用功能名，不用模糊代号
- 文档内容优先写事实和约束，不写空泛口号
- 如果功能跨三端，`平台映射` 必须明确到目录层级
